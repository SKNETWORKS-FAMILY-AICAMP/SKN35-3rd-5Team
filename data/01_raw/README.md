## 핵심 위치

- 관리 지침 **13~15쪽 금지 표현 표** → 금지 표현 사전(`banned_terms.json`) 재료

- 화장품법 제13조(부당한 표시·광고 금지), 제14조(실증)
- 시행규칙 제22조, 제23조, **별표 5** (표시·광고의 범위 및 준수사항)
- 실증규정 **별표** (표시·광고에 따른 실증자료)
- 안전기준규정 **별표 1** (사용할 수 없는 원료), **별표 2** (사용상 제한이 필요한 원료 · 최대 함량) → 성분 안전 검사 재료
- 기능성 심사규정 **별표 4** (자료제출이 생략되는 기능성화장품의 종류): 기능성 유형별 성분·최대 함량 → 성분 규칙 표 재료

## 다시 받기

성분 사전: `uv run python indexing/00_sync_ingredients.py` (`.env`의 `DATA_GO_KR_API_KEY` 필요)

법령·고시:

```
https://www.law.go.kr/DRF/lawService.do?OC={OC}&type=XML&target=law&MST=285353        # 화장품법
https://www.law.go.kr/DRF/lawService.do?OC={OC}&type=XML&target=law&ID=008741         # 시행규칙
https://www.law.go.kr/DRF/lawService.do?OC={OC}&type=XML&target=admrul&ID=2100000192523  # 실증규정
https://www.law.go.kr/DRF/lawService.do?OC={OC}&type=XML&target=admrul&ID=2100000269812  # 심사규정
https://www.law.go.kr/DRF/lawService.do?OC={OC}&type=XML&target=admrul&ID=2100000276068  # 안전기준규정
```
`OC`는 국가법령정보 공동활용(open.law.go.kr)에 가입한 이메일 ID입니다. 이번 수집은 공개 예시 값 `test`로 받았으므로, 자동화 스크립트에는 팀 계정의 OC를 `.env`에 넣어 사용하세요.
