문구 차이의 추가 검증 자료와 담당 역할은 [문구 비교 근거 v0.1](copy_comparison/README.md)에 정리했다.
공식 제목 A/B 원본 22,666행에서 같은 실험·이미지 비교 148쌍을 추출하고 기존 5제품·21문구에 검증 카드를 연결했다.
이 자료는 클릭 비교 방법을 검증하며 화장품 매출 상승률을 대신하지 않는다.

수집일 **2026-10-14**. 전날의 `top_product_copies/wrinkle_serum_sample/`를 기준으로 별도 확장했다.
회사·브랜드·ODM 관계 데이터는 확장하지 않았다. 판정기 및 Qdrant에는 적재하지 않았다.

## 다운로드한 공개 실험

[Kevin Hillstrom 원저자 설명](https://blog.minethatdata.com/2008/03/minethatdata-e-mail-analytics-and-data.html)에 따르면,
최근 12개월 구매자 64,000명을 남성상품 이메일·여성상품 이메일·미발송군에 무작위 배정하고 이후 2주를 관찰했다.
`raw/hillstrom.csv`에 원본을 내려받아 행 수·12개 필드·군·이진 결과·금액을 검증했다.
원본의 SHA-256과 다운로드 주소는 `hillstrom_download_manifest.json`에 있다.
정식 재배포 라이선스는 확인하지 못해 원본은 Git에서 제외했다.

| 군 | 고객 수 | 실제 구매자 수 | 구매자 비율 |
|---|---:|---:|---:|
| 남성상품 이메일 | 21,307 | 267 | 약1.253% |
| 여성상품 이메일 | 21,387 | 189 | 약0.884% |
| 미발송 | 21,306 | 122 | 약0.573% |

직접 계산한 값이다. 구매자 수는 상품 개수나 주문 수와 다르다. 금액은 원저자의 dollars 표기 그대로 유지했다.
**이 수치를 세럼 광고의 구매율·상승률로 쓰지 않는다.** 모델·추정 구간·대조군 평가 구현의 외부 방법 검증용이다.

[Criteo Uplift](https://ailab.criteo.com/criteo-uplift-prediction-dataset/)는 수정본 13,979,592행의 광고 처리 실험 후보로 등록했다.
압축 약297MB여서 다운로드하지 않았다. 익명 피처와 방문/전환 결과가 있으며 문구·금액·상품 개수는 없다.
원저자는 비균일 서브샘플링 때문에 원래 광고의 절대 증분 수준을 복원할 수 없다고 설명한다.

## 서비스에서 다음으로 구현할 수 있는 출력

1. **문구 판정·교정:** 기존 규정·자사 시험 근거로 수행.
2. **추천 문구의 시장 참고 사례:** 문구·플랫폼·행사 조건·공개 성과의 범위를 함께 보여줌.
3. **가정 기반 매출·판매량 시나리오:** 사용자가 입력한 클릭 수·구매율·주문/구매자·상품/주문·주문당 순매출에 따른 계산.
4. **학습된 문구 성과 예측:** 현재 데이터로는 미지원. 검증된 제품·문구·기간별 실측 자료가 추가되어야 함.

시나리오 입력 양식은 `forecast_input_template.json`이다. 숫자는 의도적으로 모두 비워 두었다.

- 예상 구매자 수 = 계획 클릭 수 × 클릭 기준 구매확률
- 예상 주문 수 = 예상 구매자 수 × 구매자당 주문 수
- 예상 상품 개수 = 예상 주문 수 × 주문당 상품 개수
- 예상 순매출 = 예상 주문 수 × 주문당 순매출

‘방문 기준 CVR’을 클릭 기준 확률에 넣지 않는다. 주문당 순매출은 할인·취소·반품·세금 기준을 맞춰야 한다.
실측으로 보정된 예측 구간이 없으면 보수/기준/낙관은 **가정 범위**라고 표시하고 신뢰구간이라 부르지 않는다.
같은 입력 조건의 추천 문구 A/B/C에 임의의 서로 다른 매출 숫자를 붙이지 않는다.

## 파일

- `product_sales_observations.jsonl`: 제품별 공개 행사 판매액 2행.
- `beauty_campaign_cases.jsonl`: 조건·측정 범위·한계를 포함한 뷰티 사례 5행.
- `sample_product_coverage.jsonl`: 어제 제품5개와 연결된 데이터 보유 현황.
- `sources.json`: 출처8개와 열람일·출처 성격.
- `benchmark_catalog.json`: 공개 실험 후보와 실제 다운로드 여부.
- `hillstrom_download_manifest.json`, `hillstrom_group_summary.json`: 다운로드 검증과 관측 집계.
- `forecast_input_template.json`: 숫자를 조작하지 않은 시나리오 연결 양식.

재생성: `python scripts/collect_sales_forecast_reference.py`.
원저자 실험 파일 다운로드·재집계: 동일 명령에 `--download-benchmark` 추가.
이 수집 명령은 실제 예측 모델을 학습하거나 팀 벡터 DB를 수정하지 않는다.
