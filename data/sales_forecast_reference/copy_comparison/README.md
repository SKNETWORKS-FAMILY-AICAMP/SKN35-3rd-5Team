# 문구 차이의 근거를 만드는 데이터·평가 설계 v0.1

준호 담당: **문구 추천의 데이터 근거와 성과 검증 체계 설계**.
수집·분석일: 2026-10-14. 현재 서비스의 규정·근거 판정은 유지하고,
추천 문구에 시장 관찰 근거와 검증 상태를 붙이는 역할이다.

## 이번에 확보·계산한 결과

| 자료 | 확보 결과 | 설명할 수 있는 차이 |
|---|---:|---|
| 기존 올리브영 제품·문구 | 5제품 / 21문구 | 어떤 소구를 어떤 가격·구성·랭킹 조건에서 사용하는가 |
| 공식 Upworthy 탐색용 원본 | 22,666패키지 / 4,873실험 | 문구·이미지 ID·노출·클릭 실측치 |
| 조건을 맞춘 비교 | **148쌍**, 실험당 최대 1쌍 | 같은 실험·같은 이미지에서 다른 제목의 관측 CTR 차이와 불확실성 |
| 화장품 연결 카드 | 5건 | 실제 시장 문구·조건 → 소구 가설 → 필요한 검증 데이터 |
| 화장품 문구별 매출 효과 | 미확보 | 예상 매출·수량·문구 상승률은 null 유지 |

Upworthy는 미국 뉴스 제목 실험이다. **화장품 소비자의 구매 반응을 대신하는 데이터가 아니다.**
CTR 계산·통제 조건·불확실성 표시를 실제 공개 실험으로 점검하는 용도로만 사용한다.
기존 뷰티 캠페인 사례 5건 및 제품 판매액 2건은 상위 폴더에 유지한다.
그 성과를 여기의 제목이나 현재 화장품 문구에 나누어 붙이지 않는다.

## 파일

- `headline_comparisons.jsonl`: 비교 148건. A/B 원문·노출·클릭·CTR·차이(pp)·95% 구간.
- `display_examples.json`: ID 정렬 순서의 첫 3건. 성과를 보고 좋은 사례를 고르지 않았다.
- `cosmetics_evidence_cards.json`: 기존 5제품의 문구·가격·구성·랭킹과 검증 가설을 연결.
- `manifest.json`: 공식 URL·SHA-256·규칙·제외 건수·라이선스·수집일.
- `../raw/upworthy_exploratory.csv`: 내려받은 원본. raw 폴더는 Git 제외.

재생성: 프로젝트 루트에서 `.\.venv\Scripts\python.exe scripts/build_copy_comparison_evidence.py`.
다른 PC는 같은 명령에 `--download`를 추가하면 공식 원본을 받는다.
API·Qdrant·판정기를 변경하거나 데이터를 적재하지 않는다.

## 비교 기준과 실제 예시

운영기관의 2024년 정정 안내에 따라 2013-06-25~2014-01-10에 걸친 **실험 전체 1,050건을 제외**했다.
현재 다운로드된 2020 CSV에는 `problem` 열이 없어 날짜 규칙을 명시적으로 적용했다.
같은 실험·비어 있지 않은 같은 이미지 ID, 서로 다른 문구 2개인 그룹만 포함한다.
각 노출 1,000 이상, 두 군 노출 비율 1.2 이하를 요구하며 실험당 이미지 ID 순서의 첫 그룹만 선택한다.
노출 균형 필터는 보조 점검이며 무작위 배정의 성공을 증명하는 검정은 아니다.
선정에 클릭률·winner·significance 필드를 사용하지 않는다.

| ID 순 첫 비교 | A 클릭/노출 | B 클릭/노출 | A CTR | B CTR | B−A |
|---|---:|---:|---:|---:|---:|
| `51436069220cb800020005bd` | 103 / 5,210 | 89 / 5,363 | 1.977% | 1.660% | −0.317pp |
| `51436074220cb800020007af` | 27 / 2,864 | 27 / 2,753 | 0.943% | 0.981% | +0.038pp |
| `51436074220cb800020007b2` | 35 / 2,623 | 39 / 2,788 | 1.334% | 1.399% | +0.065pp |

첫 비교의 95% 차이 구간은 약 **−0.835~+0.194pp**다. 0을 포함하므로 B가 더 나쁘다고 단정하지 않는다.
계산은 Wilson 비율 구간을 이용한 Newcombe 차이 구간이다.
개별 구간은 다중비교 보정 전 탐색용 구간이며, 148건 중 유리한 결과를 골라 일반적인 문구 법칙으로 발표하지 않는다.
같은 실험·이미지 외의 세부 타깃·배치·개인별 노출 이력은 미확인이다.
이미지 실물은 공개되지 않았으므로 이미지 ID 일치까지만 확인했다.

## 우리 서비스에 연결하는 방식

추천 문구마다 아래 세 종류를 구분해서 표시한다.

1. **규정·제품 근거**: 팀 판정기의 0/1/2 결과, 근거 조문·제품 시험 자료. 출시 전 사람 검토 대상.
2. **시장 관찰**: 어떤 실제 제품에서 같은 소구 유형을 사용했는지, 수집일·가격·행사·구성·URL.
3. **성과 검증 상태**: 해당 화장품 문구의 클릭·구매 성과는 미측정. 공개 제목 실험은 방법 검증 참고.

예: 아누아의 성분 소구 문구와 같은 제품의 혜택 문구를 출처와 함께 보여줄 수 있다.
그러나 이 두 문구는 위치와 목적이 다르고 노출·클릭이 없으므로 A/B 실험 결과로 취급하지 않는다.
두 방향을 참고해 **같은 위치에 들어갈 승인된 후보**를 만들고 비교 계획을 세우는 데 사용한다.
수치형 소구도 제품의 해당 시험·조건을 확인한 뒤 후보로 사용한다. 경쟁 제품 수치는 복사하지 않는다.

## 다음 실측에 필요한 데이터 계약

실제 화장품 문구 효과를 평가하려면 동일 SKU·가격·할인·구성·이미지·위치·타깃·기간을 고정하고
적격 이용자에게 후보를 무작위 배정한 실험 로그가 필요하다. 지금 광고 집행을 요청하거나 실시한 것은 아니다.
공개 자료만 사용 가능하므로 이 조건을 충족하는 공개 사례가 나올 때 연결할 계약을 준비한 상태다.

- 실험 ID, 후보 ID, 문구 원문, 노출 수, 클릭 수, 배정 방식, 실험 기간.
- 구매까지 연결할 때 주문 수·수량·순매출·광고비·반품·전환 집계 기간·분모.
- 실험 전 1차 지표·표본수·종료 기준을 정하고 결과를 보고 기간/후보를 바꾸지 않는다.
- 구매율은 클릭/노출 중 어느 분모인지 명시한다. 클릭자만 비교하면 유입 구성도 달라질 수 있어
  문구의 총 구매 효과는 무작위 배정된 노출 기준 구매율로 별도 확인한다.

노출 × CTR은 예상 클릭 수다. 그다음의 구매율·객단가까지 관측되거나 명시적 가정이 있어야 매출 시나리오가 된다.
클릭률 상승이 구매율·매출 상승으로 그대로 이어진다고 가정하지 않는다.

## 포트폴리오에 쓸 수 있는 기여 문장

> 화장품 광고 판정·교정 RAG의 추천 기준을 보강하기 위해 5제품·21문구의 시장 관찰 데이터를 연결하고,
> 공개 제목 A/B 실험 22,666행에서 조건을 맞춘 비교 148쌍을 구축했다.
> 데이터 품질 정정 이력을 반영해 위험 기간을 제외하고, CTR 차이와 불확실성을 계산하는 평가 파이프라인을 구현했다.
> 시장 참고 근거·규정 근거·성과 실측을 구분하고, 화장품 매출 효과 검증에 필요한 데이터 계약을 설계했다.

‘화장품 추천 문구의 매출을 높였다’, ‘문구 매출 예측 모델을 완성했다’는 아직 실증하지 않은 성과다.
