## 성분 기반 선별

- 내부 분석 샘플: `PUBLIC_KIEHLS_UFC` / 키엘 울트라 훼이셜 크림.
- 외부 후보: Biossance Squalane + Omega Repair Cream, 키엘 베리어 크림.
- `ingredient_profiles.json`에 공식 전성분 3제품, 출처·수집일·시장·원문·주요 소구 성분을 기록했다.
- 기존 6제품의 전성분은 추정하지 않았다. 공개 샘플은 공식몰 기능성 심사필 ‘없음’을 확인해 일반으로 등록했다.
- 공개 시험 요약 3건을 `source_kind=public_brand_summary`인 시연용 등록 자료로 연결했다. 원보고서 보유나 독립 검증을 의미하지 않는다. 기존 하이드라 샘플의 42% 시험은 복사하지 않았다.

### 키엘 공개 시험 요약 연결

`data/assets/public_analysis_products.json`의 `PUBLIC_KIEHLS_UFC.owned_evidence`에 공식몰 공개 요약 3건을 연결했다.
보습(72시간 후 수분 유지력23.5%), 외부 자극에 의한 일시적 붉은기(2주 후29.3%), 장벽 관련 경피수분손실량(공식몰+100%표기)이다.
출처 URL·대상·기간·비교조건·원보고서 미확보를 명시했다. 시험기관은 공개되지 않아 null이다.
장벽 시험의 1주·2주 시점별 값이나 수치 산식을 만들지 않았다. 참고 제품의44%와 하이드라 데모42%를 가져오지 않았다.
API 스키마가 출처 필드를 유지하고 추천 프롬프트에 공개 요약의 한계를 전달한다.
검토 대화에는 키엘 전용 예시 3개와 ‘공개 시험’ 탭을 추가했고, 해당 요청 당시 선택한 요약을 표시한다.

`kiehls_public_evidence_api_smoke.json`은 실제 API 호출 결과다.
입력은 실제 브랜드 광고가 아닌 팀 검토용 과장 초안이다. 응답에 규정 근거4개·교정 후보3개를 확인했다.
공개 요약을 적용한 시연용 자동 검토이며 실제 광고 승인이나 원보고서 검증 결과가 아니다.

선별 조건은 **공식 전성분 확인 + 같은 제형 + 양쪽에서 주요 소구로 확인한 성분의 공통점**이다.
정제수·글리세린 같은 공통 기제만으로 참고 제품을 채택하지 않는다.
영문 INCI와 한글의 명확한 동일명만 별칭 사전으로 정규화한다. 성분 계열·상업명·유사 분자를 같은 성분으로 뭉치지 않는다.
주요 성분은 공식 사이트의 강조 성분을 분석자가 표기한 것이다. 함량·배합 유사도 점수가 아니다.

함량·피부 영향·효능 동등성·매출 효과는 미측정이다. 국가·리뉴얼·실물 용기 표기 차이도 확인이 필요하다.

화면의 검토 대상은 `backend.list_products()`의 샘플 6개와 사이드바 공통 선택을 따른다.

시장 참고 제품은 합계 11개이며 기존 수집 자료를 재사용했다. 새 크롤링이나 브랜드 관계 확장은 하지 않았다.

재생성 스크립트는 원래의 세럼 카드 파일만 재생성하며 수작업 연결 정의 파일을 덮어쓰지 않는다.

### 화면의 성과 입력·비교

화면을 `제품 · 시장 근거`, `성과 입력 · 비교`, `공개 A/B 실험` 세 탭으로 나눴다.
시장 문구는 원문을 먼저 보여주는 카드로 표시하고 출처·조건은 접어서 확인한다.
성과 탭에서는 현재 PROD ID별로 문구 A/B 원문·출처/가정·기간·노출·클릭·주문·판매 수량·순매출을 입력한다.
기본값은 모두 비어 있으며 임의의 실적을 자동 주입하지 않는다.
공개 실측 입력은 동일 조건 확인과 기간을 요구하지만, 확인 체크만으로 인과 효과가 입증되지는 않는다.
현재까지 실제 화장품 문구별 실적은 확보되지 않아 가정 입력은 시나리오로만 표시한다.

- 클릭률: 클릭/노출. 차이는 pp, 상대 변화는 %로 구분한다.
- 예상 판매량/순매출: 각 후보의 관측 수량 또는 순매출/노출 × 공통 계획 노출.
- 관측 비율이 유지된다는 단순 환산이며 학습된 예측, 인과 효과, 불확실성 구간이 아니다.
- 수량·순매출·계획 노출 미입력 시 해당 결과는 산출 전으로 유지한다. 주문 수와 상품 개수는 구분한다.
- A=0일 때 상대 변화율은 미산출. 클릭률 증가를 판매량·매출 증가에 전용하지 않는다.
- 상승은 빨간 계단형 화살표, 하락은 파란 계단형 화살표, 미측정/동일은 회색으로 표시한다.
- 세션 메모리만 사용하며 API/Qdrant/공용 데이터셋에 입력값을 저장하지 않는다.

## 비교 기준과 실제 예시

운영기관의 2024년 정정 안내에 따라 2013-06-25~2014-01-10에 걸친 **실험 전체 1,050건을 제외**했다.
현재 다운로드된 2020 CSV에는 `problem` 열이 없어 날짜 규칙을 명시적으로 적용했다.
같은 실험·비어 있지 않은 같은 이미지 ID, 서로 다른 문구 2개인 그룹만 포함한다.
각 노출 1,000 이상, 두 군 노출 비율 1.2 이하를 요구하며 실험당 이미지 ID 순서의 첫 그룹만 선택한다.
노출 균형 필터는 보조 점검이며 무작위 배정의 성공을 증명하는 검정은 아니다.
선정에 클릭률·winner·significance 필드를 사용하지 않는다.

| ID 순 첫 비교 | A 클릭/노출 | B 클릭/노출 | A CTR | B CTR | B−A |
|---|---:|---:|---:|---:|---:|
| `51436069220cb800020005bd` | 103 / 5,210 | 89 / 5,363 | 1.977% | 1.660% | −0.317pp |
| `51436074220cb800020007af` | 27 / 2,864 | 27 / 2,753 | 0.943% | 0.981% | +0.038pp |
| `51436074220cb800020007b2` | 35 / 2,623 | 39 / 2,788 | 1.334% | 1.399% | +0.065pp |

첫 비교의 95% 차이 구간은 약 **−0.835~+0.194pp**다. 0을 포함하므로 B가 더 나쁘다고 단정하지 않는다.
계산은 Wilson 비율 구간을 이용한 Newcombe 차이 구간이다.
개별 구간은 다중비교 보정 전 탐색용 구간이며, 148건 중 유리한 결과를 골라 일반적인 문구 법칙으로 발표하지 않는다.
같은 실험·이미지 외의 세부 타깃·배치·개인별 노출 이력은 미확인이다.
이미지 실물은 공개되지 않았으므로 이미지 ID 일치까지만 확인했다.

## 우리 서비스에 연결하는 방식

추천 문구마다 아래 세 종류를 구분해서 표시한다.

1. **규정·제품 근거**: 팀 판정기의 0/1/2 결과, 근거 조문·제품 시험 자료. 출시 전 사람 검토 대상.
2. **시장 관찰**: 어떤 실제 제품에서 같은 소구 유형을 사용했는지, 수집일·가격·행사·구성·URL.
3. **성과 검증 상태**: 해당 화장품 문구의 클릭·구매 성과는 미측정. 공개 제목 실험은 방법 검증 참고.

예: 아누아의 성분 소구 문구와 같은 제품의 혜택 문구를 출처와 함께 보여줄 수 있다.
그러나 이 두 문구는 위치와 목적이 다르고 노출·클릭이 없으므로 A/B 실험 결과로 취급하지 않는다.
두 방향을 참고해 **같은 위치에 들어갈 승인된 후보**를 만들고 비교 계획을 세우는 데 사용한다.
수치형 소구도 제품의 해당 시험·조건을 확인한 뒤 후보로 사용한다. 경쟁 제품 수치는 복사하지 않는다.

## 다음 실측에 필요한 데이터 계약

실제 화장품 문구 효과를 평가하려면 동일 SKU·가격·할인·구성·이미지·위치·타깃·기간을 고정하고
적격 이용자에게 후보를 무작위 배정한 실험 로그가 필요하다. 지금 광고 집행을 요청하거나 실시한 것은 아니다.
공개 자료만 사용 가능하므로 이 조건을 충족하는 공개 사례가 나올 때 연결할 계약을 준비한 상태다.

- 실험 ID, 후보 ID, 문구 원문, 노출 수, 클릭 수, 배정 방식, 실험 기간.
- 구매까지 연결할 때 주문 수·수량·순매출·광고비·반품·전환 집계 기간·분모.
- 실험 전 1차 지표·표본수·종료 기준을 정하고 결과를 보고 기간/후보를 바꾸지 않는다.
- 구매율은 클릭/노출 중 어느 분모인지 명시한다. 클릭자만 비교하면 유입 구성도 달라질 수 있어
  문구의 총 구매 효과는 무작위 배정된 노출 기준 구매율로 별도 확인한다.

노출 × CTR은 예상 클릭 수다. 그다음의 구매율·객단가까지 관측되거나 명시적 가정이 있어야 매출 시나리오가 된다.
클릭률 상승이 구매율·매출 상승으로 그대로 이어진다고 가정하지 않는다.

## 포트폴리오에 쓸 수 있는 기여 문장

> 화장품 광고 판정·교정 RAG의 추천 기준을 보강하기 위해 5제품·21문구의 시장 관찰 데이터를 연결하고,
> 공개 제목 A/B 실험 22,666행에서 조건을 맞춘 비교 148쌍을 구축했다.
> 데이터 품질 정정 이력을 반영해 위험 기간을 제외하고, CTR 차이와 불확실성을 계산하는 평가 파이프라인을 구현했다.
> 시장 참고 근거·규정 근거·성과 실측을 구분하고, 화장품 매출 효과 검증에 필요한 데이터 계약을 설계했다.

‘화장품 추천 문구의 매출을 높였다’, ‘문구 매출 예측 모델을 완성했다’는 아직 실증하지 않은 성과다.

## 시장 문구 판정 (R0 규칙 판정기 연결)

수집한 시장 문구 전체(올리브영 상위 세럼 5제품 + 시장 참고 11제품, 46문구)를 팀 규칙 판정기로 검토해
`market_copy_judgements.jsonl`과 `market_copy_judgement_summary.md`를 만든다. 화면 연결용 도우미는 `app/services/market_judgements.py` (load_copy_judgements, judgement_counts, JUDGE_BADGE).

- 재생성: `uv run python scripts/judge_market_copies.py` (규칙 JSON을 바꾸면 다시 실행)
- 원본 수집 파일(`copies.jsonl` 등)의 `judge_level: null`은 그대로 두고 결과는 별도 파일에 쓴다.
- 외부 제품의 시험 원자료가 없으므로 보유 근거는 '없음'으로 판정한다. 수치·시험 표현은 '근거 확인 필요(1)'가 된다.
- 기능성 유형은 공개 고시로 확인된 것만 쓴다. 미확인 제품은 일반·기능성 두 번 판정해 결과가 갈리면
  '기능성 심사 여부 확인 필요'로 표시하고 위반으로 단정하지 않는다.
- 함량 표기('레티놀 2%')는 효능 수치로 보지 않는다. 성분명만 있는 '콜라겐 토너'는 실증 대상 주장으로 보지 않는다.
- 발표에서는 브랜드명을 가리고 "상위 제품 문구 중 N%가 근거 확인 필요 수준"처럼 분포로만 인용한다.
  판정 결과와 순위·매출의 인과는 주장하지 않는다.
