# 기존 수집 자료 연결 점검

> 후속 구현 완료: 이 문서는 연결 전 점검 기록이다. 시장 참고 생성 및 두 화면 공유 구현은 `GENERATION_INTEGRATION.md`를 참고한다.

점검일: 2026-10-14. 현재 kjh 체크아웃의 자료·생성 경로와 로컬에 저장된 origin/dev, kgm, lhm, lsh, yjh의 데이터 경로를 확인했다. 원격 fetch, 다른 브랜치 병합, Cloud Qdrant 내용 조회는 수행하지 않았다. 아래 개수는 로컬 파일 기준이며 최신 원격·운영 DB 개수를 뜻하지 않는다.

## 결론

기존 자료로 시장 문구를 참고하는 광고문 생성의 첫 구현이 가능하다. 우선 수집보다 연결을 보완한다. 제품별 전성분·광고 원문이 없는 카테고리만 이후 추가 수집한다.

## 생성 경로에서 확인한 연결 공백

1. `generation/nodes.py`는 제품·실증·생성 요청으로 규정을 검색한 뒤 생성기를 호출한다. 시장 제품·실제 문구를 검색하거나 전달하는 단계가 없다.
2. `models/generation_prompts.py`에는 제품·광고 조건·보유 실증·표현 상한·규정만 있다. 시장 사례용 입력 구역이 없다.
3. `app/services/peer_market.py`는 광고문 생성기와 별도로 고정 후보를 만든다. 같은 제품이라도 광고문 생성 화면과 매출 화면의 문구가 달라지는 원인이다.
4. 전성분 비교는 `domain/ingredients.py`, 주요 성분군 매칭은 `peer_market.py`로 나뉘어 있다. 하나의 비교 서비스에서 확인 수준을 구분해 제공할 필요가 있다.
5. 시장 로더가 원본의 출처·시험 조건·가격 구성 정보를 일부 생략한다. 추천 이유를 설명하려면 원문과 제한 조건을 함께 유지해야 한다.
6. `_merge_same_product`는 같은 브랜드·제형·공통 성분을 같은 제품으로 합친다. 같은 브랜드의 다른 SKU를 합칠 수 있으므로, 명시적 동일 제품 매핑만 병합해야 한다.

## 기존 자료로 연결하는 순서

### 1. 공통 시장 참고 서비스

입력: 등록 제품의 제형, 실제 주요 성분/전성분, 기능성 표시.

기존 제품·가격·문구 원문·전성분 프로필을 product_id/copy_id/source_id로 연결한다. 동의어 사전은 화학적으로 동일한 성분명 정규화에 쓰고, 히알루론산 계열·레티노이드 계열 같은 넓은 그룹 비교는 별도 표기한다. 같은 계열을 같은 분자·농도·효능으로 표시하지 않는다.

결과: 같은 제형의 후보, 공통 주요 성분, 다른 주요 성분, 실제 광고 원문, 원문 위치, URL·수집일, 시험 조건·가격·행사 조건, 성분 확인 수준. 조건이 안 맞거나 전성분이 없으면 그 한계를 표시한다. 제품명에서 성분을 임의 추정하지 않는다.

### 2. 생성기에 시장 사례 전달

규정 검색은 현재 경로를 유지한다. 별도로 선별한 시장 사례를 생성기의 표현 참고 입력으로 전달한다. 시장 사례 ID는 M1 등으로, 법령 근거 ID L1 등과 구분한다. 순위·인기만으로 문구의 효능이나 적법성을 승인하지 않는다.

생성 결과에 참고한 사례 ID, 참고한 표현 방식, 우리 제품에서 사용한 사실·실증을 남긴다. 다른 제품에만 있는 성분·기간·수치·인증·순위를 복사하지 않는다. 공개 시험 요약과 내부 원보고서는 출처 수준을 구분한다.

### 3. 기존 검증과 두 화면 공유

생성 후보는 기존 규칙·검증기를 통과시킨다. 현재 생성 그래프는 규정 RAG 검색 후 규칙/verifier로 후보를 검증하며, 후보별 전체 검토 그래프 호출과는 다르다. 상세 근거 판정이 필요하면 선택 후보를 ReviewService.review_single에 전달한다.

선택 문구·제품 정보·선택 실증·광고 조건·시장 사례 버전을 함께 저장해 광고문 생성과 예상 매출이 같은 결과를 사용한다. 입력 근거가 달라지면 재생성·재검토를 안내한다. 매출 화면의 별도 고정 후보 생성은 공통 결과로 대체한다.

## 현재 제품으로 가능한 예시

- 수분 진정 수딩 토너: 주요 성분 히알루론산·판테놀을 입력하면 보완한 아누아 토너 원문을 참고할 수 있다. 아직 토너 표본이 적으므로 시장 전체 경향이라고 표현하지 않는다.
- 키엘 울트라 훼이셜 크림: 기존 공식 전성분 프로필의 Biossance 공통 스쿠알란을 표현 참고로 활용할 수 있다. 해외 문구의 한국 허용성·리뉴얼 동일성·효능 동등성은 별도 확인 대상이다.
- 레티노이드 세럼: 기존5개 샘플의 실제 문구·조건을 활용할 수 있다. 미확인 기능성 유형은 확정하지 않으며 다른 제품의 시험 수치를 복사하지 않는다.
- 탈모 샴푸·여드름 클렌저: 규정·적발 사례는 있지만 비교할 시장 제품의 전성분·실제 광고 문구 표본은 부족하다. 이 카테고리를 확장할 때만 추가 수집한다.

## 이번 점검의 작업 범위

자료 구조·개수·호출 경로 점검과 연결 설계만 작성했다. 생성 기능 코드 변경·신규 외부 수집·법령 개정 검증·원격 병합·운영 DB 재색인은 수행하지 않았다.
