# 시장 문구를 참고하는 공통 생성 흐름

2026-10-14 구현. 새 외부 수집 없이 기존 제품·문구·공식 전성분·원료 동의어 자료를 재사용했다.

## 연결

- `src/cosmetic_agent/market_reference.py`: 두 화면과 서버가 공유하는 시장 비교 서비스. 기존 UI 모듈은 호환용 재노출만 한다.
- 원료 사전에서 모호하지 않은 표준명·영문명·동의어를 정확 일치로 대응한다. 히알루론산 등 성분군은 넓은 비교 기준이며 동일 분자·함량·효능을 뜻하지 않는다.
- 시장 원문에는 copy_id, product_id, URL, 수집일, 위치·조건을 유지한다. 기존 공식 전성분 크림 프로필도 연결한다.
- 생성의 표현 참고는 동일 제형·공통 주요 성분이 있는 사례 최대6개를 사용한다. 없으면 우리 제품·규정만으로 생성한다.
- 시장 사례는 M1 등, 법령 근거는 L1 등으로 구분해 프롬프트에 전달한다. 후보 응답에 `market_reference_ids`, `market_application`, 전체 응답에 `market_references`를 추가했다.
- 시장 사례는 보유 실증으로 넣지 않는다. 없는 사례 ID·확인되지 않은 성분 소구·보유 근거 없는 수치는 검증에서 제외한다. 표현 검증은 최종 광고 승인·원보고서 검증을 뜻하지 않는다.
- 같은 브랜드·공통 성분만으로 다른 SKU를 합치지 않는다. 확인된 아누아 동일 본품 매핑만 명시적으로 병합한다.

## 화면 사용

1. 제품과 사용할 실증 자료를 선택한다.
2. 광고문 생성에서 요청·채널·분위기·길이를 정해 생성한다.
3. 후보의 시장 표현 반영 설명과 비교 원문·출처를 확인한다.
4. **이 문구를 매출 시나리오에 사용**을 누른다.
5. 매출 화면은 공통 생성 결과 중 선택한 문구를 그대로 사용한다. 후보를 변경할 수 있고 별도의 고정 후보를 만들지 않는다.
6. 제품·성분·제형·선택 실증이 달라지면 기존 결과를 재사용하지 않고 재생성을 안내한다. 등록 및 생성 결과는 브라우저 세션 범위다.

시장 자료를 연결해도 문구별 매출 상승률이 확보되는 것은 아니다. 매출 계산의 기존 가정 범위는 그대로 유지한다.

## 확인 결과

- 시장 원문 전달·공식 전성분 재사용·SKU 분리·잘못된 사례/성분/수치 차단·화면 간 문구 선택 공유 및 실증 변경 후 무효화 테스트 추가.
- 실제 OpenAI/Qdrant 연동 `/generate` 호출 HTTP200: 토너 후보3개, 시장 사례1개, 규정 근거6개. 시험 자료 없는 가상 자사 토너로 확인했고 시장 시험 수치를 자사 실증으로 복사하지 않았다.
- 응답 기록: `data/sales_forecast_reference/copy_comparison/market_generation_api_smoke.json`. 이는 연결 검증이며 문구 성과·매출 평가가 아니다.

원료 전체 동의어의 제품별 정확성, 해외 표현의 국내 적합성, 원문 권리·상품 버전은 실제 운영 전 추가 검토 대상이다. 표본이 적은 카테고리는 시장 전체 경향으로 일반화하지 않는다.
