# 창의적 광고 문구 출력 v1

사용자가 제공한 광고 이미지5장의 표현 구조를 감각적 비유·텍스처·시간과 루틴·성분 이야기·상황과 실증으로 정리했다. 실제 브랜드 원문을 생성용 정답 문구로 복제하지 않았다.

- 출력: 헤드라인 + 설명 문구 + 선택한 제품 시험의 조건 별첨.
- text는 서버가 헤드라인과 설명 문구로 다시 조립하고 전체를 역검증한다. 숨겨진 과장 헤드라인을 따로 내보내지 않는다.
- 시험 조건은 모델이 만드는 필드가 아니다. 선택한 E번호의 등록 자료를 그대로 조립하고 공개 요약/원보고서 미확보를 표시한다.
- 성분 정보I, 시장 원문M, 창작 구조C, 제품 실증E, 법령L의 역할을 구분한다.
- 레퍼런스의 브랜드명·독자 기술·자연유래 비율·환경·수치·시간을 자사 주장으로 옮기지 않는다.
- 창의성은 규정 회피가 아니라 비유·리듬·장면·메시지 구성에서 만든다. 기능성 범위와 제품별 실증 제한은 유지한다.
- 조건 별첨은 현재 등록 내용의 보존이며 시험 원본 확인·최종 광고 승인이 아니다. 광고에 사용할 때 본문과 함께 검토한다.

## 검증과 확인

- 구조 예시는 프롬프트에 그대로 넣지 않는다. 동일 예시 헤드라인의 복사·후보 간 동일 헤드라인도 검증에서 제외한다.
- 수치 설명은 일차 검증을 통과한 후 선택한 제품 시험 value의 원문으로 고정하고 다시 검증한다. 비교 기준·지표 의미를 모델이 바꾸지 않도록 한다.
- '72시간 후'를 '72시간 동안'으로 바꾸는 시간 범위 확대도 차단한다.
- 일부 구조화 후보가 탈락하면 사유를 전달해 최대2회 다시 생성한다. 끝까지 일부만 통과하면 통과한 후보만 제공하고 안내한다.
- 전체 회귀186개와 추가 재생성·수치 원문 보존 테스트를 통과했다. 테스트는 최종 광고 승인 검증이 아니다.
- `api_smoke.json`: 실증 없는 토너·공개 시험 요약이 있는 키엘 크림의 실제 API 응답. 각각 헤드라인·설명 후보3개를 확인했다.
- 키엘 샘플 예시: 「시간이 지나도, 촉촉함이 남아있다.」 아래에 「도포72시간 후 수분 유지력23.5% (무도포 부위 대비)」 원문과 등록 대상·기간·출처 조건을 함께 출력한다. 이는 생성 예시이며 실제 브랜드 광고 원문이 아니다.
